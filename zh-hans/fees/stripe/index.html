Stripe 的美国本地卡费率是每笔成功交易 2.9% + 30¢，没有月费。国际卡加 1.5%，币别转换加 1%，争议（chargeback）每笔 US$15，不论输赢。

跨境卖家用台湾或香港帐户收美元、买家多半持海外卡，实务上费率会落在 5.4% + 30¢ 左右。固定 30¢ 让小额订单特别贵：一笔 US$5 的订单光固定费就是 6%，加起来 8.9%。Stripe 是收款工具不是市场，流量、店面与退款政策都由你负责——这正是它费率低的原因。

适用与注意：自有网站、SaaS、开立发片与自行开发的结帐流程。国际卡加 1.5%、币别转换加 1%，争议每笔 US$15；小额订单的 30¢ 固定费最伤。

常见问题

Stripe 的手续费怎么算？

刷卡处理 2.9% + US$0.30；跨境附加 2.5%（国际卡 1.5%＋币别转换 1%）（ASSUMPTION：台湾／香港帐户收美元、买家持海外卡）。

Stripe 卖一件 US$50 要付多少？

平台费 US$3.00，有效费率 6.0%，实拿 US$47.00（约 NT$1,500）。

Stripe 适合什么商品？

自有网站、SaaS、开立发片与自行开发的结帐流程。要特别注意的是：国际卡加 1.5%、币别转换加 1%，争议每笔 US$15；小额订单的 30¢ 固定费最伤。

Stripe 的费率还会变吗？

会。本页费率查核日为 2026-11-11，平台常在年中或档期前调整；虾皮台湾站已公告 2026/12/11 起再调整费率。定价前请以官方费率页与你的卖家后台帐单为准。
